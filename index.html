REMOTE TOOL CONNECTOR

Connect another MCP server

Connect a remote Streamable HTTP MCP endpoint so Agent mode can discover its tools.

MCP · HTTP
Not connected. Enter a remote HTTPS MCP endpoint and connect.
How to connect
  1. Copy the Streamable HTTP endpoint URL from your MCP provider.
  2. Enter the URL and optional bearer token above, then save.
  3. Keep read-only mode on and click Connect MCP.
  4. Enable Agent mode in Chat and ask it to use one of the connected tools.

This connector supports remote HTTPS Streamable HTTP and optional Bearer-token authentication. It does not launch local stdio processes or perform OAuth sign-in. The token is stored in this browser's local storage and is not encrypted. Private/local network URLs are blocked. Unknown or write-capable tools are blocked in read-only mode; turning it off still requires approval for each write call.
