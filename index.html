⚠
What Agent mode means here

Agent mode can create projects and edit files only inside the local projects folder. File deletion and allowlisted build/test commands ask for your approval. This is not an operating-system sandbox: only approve commands and projects you trust. Tool calling must also be supported by the selected model/provider.

⌘
GitHub MCP

The repository includes a GitHub MCP configuration for MCP-compatible hosts. It starts in read-only mode. It is a separate integration and is not yet loaded directly by Vibe Calling's own chat agent. See docs/agent-tools-and-mcp.md.
