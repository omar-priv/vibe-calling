# GitHub management

1. Confirm owner/repository and inspect default branch, recent commits, project structure, and contributor guidance.
2. Read relevant files and tests before editing. Never overwrite unrelated user work.
3. Create a feature branch from the current default branch for non-trivial changes.
4. Keep secrets, tokens, private data, and generated build artifacts out of commits.
5. Update docs, tests, and duplicated bundles when needed.
6. Run available local checks and inspect GitHub Actions. Distinguish CI checks from real local/browser runs.
7. Review the diff for unintended changes and security regressions.
8. Open a clear PR with summary, test evidence, and limitations. Do not merge without user permission unless explicitly authorized.
9. Never claim a commit, branch, test, PR, or merge exists until GitHub confirms it.
10. Report the branch, PR link, and exact next action the user must take.
