# Web Research

1. Search official documentation, changelogs, API references, and source repositories first.
2. Confirm the source is current and distinguish publication date from the date an event or release occurred.
3. Cross-check material claims with a second reliable source; use community reports to surface failure modes, not as sole authority.
4. When researching model catalogs, verify API availability, endpoint compatibility, free-tier status, and limits separately.
5. Preserve exact model identifiers, version numbers, URLs, and dates.
6. Cite claims at the point of use and explain uncertainty or conflicting evidence.
7. Never infer a feature is free, available, or production-ready from a marketing label alone.
